# SacredConnect — Ceremony Catalog (MVP-Complete)

This is a **complete starter catalog** of Hindu ceremonies/ritual services for an India-first platform (starting with Chennai).  
Each item uses **simple English** as the primary label, and the traditional term is included in parentheses so users from any background can still recognize it.

> Note: This is **not seed data**. Nothing here is automatically inserted into MongoDB.  
> Use it as your master list for manual entry or future import tooling.

---

## How to name services (recommended)
- **Primary name (English-first):** what any user understands quickly
- **Traditional name (in parentheses):** optional but helpful
- Example: **Housewarming Ceremony (Griha Pravesh)**
